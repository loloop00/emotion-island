# 模板路由 / Template routing

这份参考把项目中已经确认的案例结构整理成路由表。它只规定“哪类关系适合哪种构图”，不授权复用旧案例原文案或核心寓意图形。

## 路由表 / Routing table

| case family | 适用信号 / signals | 画面关系 | 常用模板 | 动画重点 |
|---|---|---|---|---|
| `choice` | 选择、试错、机会、要不要、分叉 | 一个决策点分成两条路径，结果不同 | `choice` | 先画决策点和分支；失败路径先落地；尝试路径可以经历一次失败再出现额外可能 |
| `timeline` | 今天、长期、坚持、时间变化、后来 | 四个时间节点沿一条基准线变化 | `timeline`，可组合 `comparison` | 基准线从左到右揭示；阶段依次出现；最后保留完整总结图 |
| `obstacle` | 障碍、卡住、够不到、困难 | 同一障碍下的受阻动作和渐进解决 | `obstacle`，可组合 `action` | 障碍固定；受阻侧采用“尝试—差一点—回落”；行动侧逐步累积 |
| `comparison_action` | 两种做法、误区、对比、开始、微行动 | 同一个生活问题的状态 A 与行动 B | `comparison`，可组合 `action` 或 `obstacle` | 先让差异可见，再出现局部动作和可见结果；最后定格 |

`comparison` 是左右双栏或上下分区的布局模板；`action` 是路径、砖块或单位进度的动作模板。`comparison_action` 通常需要二者组合，但仍必须只保留一个核心隐喻。

## 模板槽位摘要 / Slot summary

### `choice`

- 结构：一个决策点、两条分支、两个短标签。
- 必需元素：分支线、失败结果、决策/尝试人物、三个确定性文字槽。
- 适合动作：停在决策点、抬手或迈一步、失败后出现额外可能。
- 注意：不要用长解释句；结果符号或结果物必须服务于新主题，不能直接复刻旧的 X/对勾案例。

### `timeline`

- 结构：四个短时间标签、同一对象的四个阶段，可选底部总结对比。
- 必需元素：基准线、四个阶段对象、四个文字槽。
- 适合动作：由难到易、由少到多、由停滞到前进；动作幅度随阶段变化。
- 注意：不要为了塞总结图压缩上方留白；颜色由对象语义决定。

### `obstacle`

- 结构：一个固定障碍、一个受阻区域、一个渐进路径或替代动作。
- 必需元素：障碍、梯子/砖块/路径、两个人物、两侧标签。
- 适合动作：跳—差一点—回落，或放置—停顿—再走一步。
- 注意：不能把高墙改成平台，也不能把逐步形成的路径直接画成完成后的楼梯。

### `comparison`

- 结构：左右两栏或上下分区，两个状态保持相近视觉权重。
- 必需元素：左右/上下状态物、两侧人物、两侧短标签；分割线可选。
- 适合动作：先分别揭示，再交替呈现结果；末帧至少保留约一秒。
- 注意：两侧必须是同一个生活问题的两种处理方式，而不是两个无关物件的拼贴。

### `action`

- 结构：一条逐步形成的路径、单位元素或目标标记。
- 必需元素：单位元素、进度路径、放置或移动人物。
- 适合动作：一格一格、一次一小步，每次动作后短暂停顿。
- 注意：不能先显示完整路径再假装累积；每一步都要被看见并理解。

## 不得复用的核心隐喻 / Do-not-reuse core metaphors

本项目已使用或已验收的核心图形，不作为新视频的核心：

- 高墙 + 砖块路径
- 梯子/台阶 + 大步小步
- 分叉选择 + X/对勾
- 今天/下周/下个月/一年后的时间线
- 方块变圆或“困难圆球”

最近台账中的风浪与舵、背包、火苗、云雾、盒门、风筝、雨伞、锅盖、新鞋和笑脸面具，也应视为已经使用过的主题图形；除非用户明确要求复刻或改编，否则换一个生活入口和核心隐喻。

## 选择失败时 / If routing fails

如果主题不能被一个模板的槽位和动作解释，先改写主题与极短文案；不要用额外文字、装饰或第二个隐喻补洞。无法判断时可以使用 `comparison_action`，但仍要通过“文字—画面—结果”和遮字/遮画测试。
